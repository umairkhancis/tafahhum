# Project Tahqeeq (تحقيق)

This project is about publishing white papers based on the current manifestation and establish its root causes and propose the way forward.

## Format
- Headline: Asking relatable but intriguing question?
- Effects being experienced in the form of insights from interviews from relevant partipants and practicioners.
- Identify common causes from effects and eventually the essential root cause among them.
- Run inductive reasoning using statistics and deductive reasoning through syllogism and estabilished conclusions.
- Propose the pragmatic way forward.
